<h1 align="center">Sample for Activating a WinRT Class Manually</h1>

The sample code activates a WinRT class for manipulating a binary file for application automatic jump list.
Uncommentted code is for overwriting a value for so-called 'action count' which is internally used to determine a folder should be regarded as a frequently used folder in Explorer's sidebar and in the Quick Access folder.

## Building from the source

1. Prerequisites
    - Windows 10 (Build 10.0.17763.0) onwards and Windows 11
    - Visual Studio 2026
    - .NET 10 SDK
2. Clone the repo
3. Open the solution
4. Build the solution
