<h1 align="center">Sample for Activating a WinRT Class Manually</h1>

The sample code activates a WinRT class for manipulating a binary file for application automatic jump list.
Uncommentted code is for overwriting a value for so-called 'action count' which is internally used to determine if a folder is a frequently used folder and should be shown in the Explorer's sidebar and in the Quick Access folder.
